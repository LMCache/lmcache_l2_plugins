Welcome to LMCache L2 Plugins!
==============================

.. figure:: ../../asset/logo.png
   :width: 60%

.. rst-class:: hero-tagline

**Vendor L2 adapter plugins for LMCache.**

This repository is the upstream-maintained community home for L2 storage
integrations. LMCache core defines the adapter interface and loads external
implementations; this project hosts plugins and their integration guides.

Start with the installation guide, then choose a plugin for your storage backend.
For the core adapter contract and serving-engine setup, see the
`LMCache documentation <https://docs.lmcache.ai/>`_.
