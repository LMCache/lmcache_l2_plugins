Design Documents
================

Design documents live in ``docs/design/``, separate from the user-facing site,
following the same convention as LMCache core. The directory mirrors the
``lmcache_l2_plugins/`` package tree: design notes for
``lmcache_l2_plugins/autumn/`` belong in ``docs/design/autumn/``.

See the repository's
`design document guidelines <https://github.com/LMCache/lmcache_l2_plugins/tree/main/docs/design>`_
for placement and writing conventions. Add a design document when architecture,
ownership, concurrency, or failure handling needs explanation beyond code and
docstrings.
